# AI Tools for Acute Care

A free, searchable directory of the AI tools in the AI Toolkit for Acute Care Teams, updated for the WHO Acute Care Action Network (November 2026).

Site: https://shamadpatel-byte.github.io/acute-care-ai-toolkit/

Full toolkit (PDF): https://drive.google.com/drive/folders/1yChRqC6GRnG7QkR0zjboHb6qmnhG-6h8

Prices and features change often. Inclusion is not an endorsement. AI assists. Humans decide. De-identify data. Verify before acting.
